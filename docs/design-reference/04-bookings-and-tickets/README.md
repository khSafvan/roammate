## 1. 16:9 Airline Boarding Passes (`flight-ticket-16-9-john.png` & `flight-ticket-16-9-jane.png`)

Tactile boarding passes styled after authentic commercial airline tickets.

| Passenger 1: John | Passenger 2: Jane |
| :---: | :---: |
|  |

### Key Features:
- **Classic 16:9 Aspect Ratio**: Optimized for desktop lookbooks and mobile viewports.
- **Flight Route Graphics**: Depicts departure/arrival airport codes, local time zones, overnight `+1` badge, and animated aircraft trajectory.
- **Personalized Passenger Tags**: Individual passenger names (**John** / **Jane**) with seat assignment.
- **Perforated Tear-off Stub**: Perforated dashed divider separating passenger details from boarding pass barcode, PNR, and gate time.

## 2. 4:3 Hotel Room Key Cards (`hotel-key-card-4-3.png`)

Tactile hotel vouchers designed as luxury room key cards.



### Key Features:
- **Aspect Ratio 4:3**: Realistic credit-card / key-card proportions.
- **Analog Skeuomorphism**: Deep sapphire gradient, gold EMV chip graphic, and vertical magnetic stripe.
- **Stay Parameters**: Check-in/check-out dates, suite room type, address, and booking reference.
