# 🧳 02. Trips Catalog & Journey Cards

This directory contains visual captures and specifications for the trips overview catalog and individual journey cards.

---

## 1. Trips Catalog Overview (`trips-list-overview.png`)

The primary landing screen displaying all active, upcoming, and archived journeys in the user's vault.



### Key Features:
- **Hero Metrics**: Aggregate counters for Total Journeys, Itinerary Days, and Flight Tickets.
- **Filter Tabs**: Quick toggling between `All Journeys`, `Upcoming`, and `Completed`.
- **Primary CTA**: "Plan New Trip" / "Add Journey" button to create or import trips.

---

## 2. Journey Overview Card (`trip-card-detail.png`)

High-density summary card for an individual travel itinerary.



### Key Features:
- **Destination & Status Tag**: Visual badge showing country/city and current status (`Active`, `Upcoming`).
- **Schedule & Operational Window**: Departure dates, calendar duration, and daily operational bounds (e.g. `09:00 – 23:00`).
- **Tactile Metrics Strip**: At-a-glance count of stops, flights, and vouchers.
- **Readiness Ring**: Circular percentage badge showing trip preparation score.
- **Actions Strip**: 1-click access to open journey, edit trip settings, or export universal backup.
